> 本文档是你在本课程中要完成的实战项目说明书。
> 你需要根据本任务书中的**功能和细节描述**来：

## 1. 项目背景与目标

### 1.1 项目背景

在校园生活中，学生的信息获取、二手交易、服务预约、消息通知等往往分散在不同渠道（微信群、QQ群、公告栏等），体验零散、效率不高。

本项目希望通过一个统一的**「iCampus · 智慧校园生活 App」**，为在校学生提供一个集成的校园信息与服务入口。

### 1.2 项目目标（1.0 版本）

- 提供**一个账号登录入口**，让学生以学号/手机号登录 App；
- 提供**公告查看**、**校园二手交易**、**校园服务预约**、**消息通知**、**个人中心**等核心功能；
- 项目完成后，App 应达到：
  - 可以正常登录、退出登录；
  - 可以完整浏览公告、二手信息、服务信息；
  - 可以发布二手物品、提交服务预约；
  - 可以收到与自己相关的消息通知；
  - 可以查看和编辑个人信息。

> 注：本任务书只要求**学生端 App**，不要求开发后台管理系统。后端使用 **SpringBoot** 搭建 RESTful API 服务，为前端提供真实数据接口。

## 2. 目标用户与使用场景

### 2.1 目标用户

- 本校在读本科生（为主）
- 辅助用户（可选/想象）：辅导员、学生干部、校园运营人员（给消息/公告一个“发布者”身份）

### 2.2 典型使用场景举例

1. **查看公告**
   - 学生打开 App，看到最新教务/活动公告；
   - 点击查看某条讲座详情，了解时间地点。
2. **发布二手物品**
   - 学生想卖二手教材或电子产品；
   - 打开「二手」模块，发布商品信息和图片；
   - 其他同学浏览并联系客服/联系他。
3. **预约服务**
   - 学生想预约自习室、报修宿舍设备、申请跑腿代取快递；
   - 打开「服务」模块，提交预约表单；
   - 后续通过“我的预约”和消息了解处理进度。
4. **接收消息通知**
   - 当预约状态变化、二手物品被标记已下架/有系统通知时；
   - 在「消息」里能看到相关提醒，并在首页或 TabBar 上看到未读红点。
5. **管理个人信息**
   - 登录后可更换头像、修改昵称/签名；
   - 在设置中切换深色模式（可选）或退出登录。

### 5.1 账号与登录模块

#### 5.1.1 启动检查逻辑（可与首页合并）

**目的**：
App 打开时检查用户是否已经登录，决定跳转到登录页还是首页。

**逻辑描述**（非独立页面，原型可只用说明文字标注在首页）：

1. App 启动时读取本地是否有有效登录凭证（如 token）。
2. 若有：
   - 直接进入首页。
3. 若无：
   - 跳转到登录页。

> 原型中可以在首页画布上标注：
> “首次打开无登录信息 → 从启动进入登录页；有登录信息 → 直接展示此页面”。

---

#### 5.1.2 登录页

**页面名称**：登录页
**页面入口**：

- 启动检查未登录时自动进入；
- 用户在“我的”页面点击“登录/切换账号”时进入。

**页面结构布局**：

1. **顶部区域**
   - 左上角：返回按钮（从“我的”页面进入时才显示；从启动进入时可隐藏）；
   - 中间：App Logo 或名称（“iCampus”文字 + 简单图标）。
2. **中部表单区域**
   - 文本标题：“欢迎登录 iCampus”
   - 输入项：
     1. **账号输入框**
        - 标签：`学号 / 手机号`
        - 占位提示：`请输入学号或手机号`
        - 类型：文本，限制长度（如 11~20 字符）
        - 校验规则：
          - 必填；
          - 可接受：数字/字母混合（学号）或 11 位数字（手机号）。
        - 错误提示示例：
          - “账号不能为空”
          - “请输入正确的学号或手机号”
     2. **密码输入框**
        - 标签：`密码`
        - 占位提示：`请输入密码`
        - 类型：密码（输入内容以圆点显示）
        - 校验规则：
          - 必填；
          - 长度至少 6 位。
        - 错误提示：
          - “密码不能为空”
          - “密码长度至少为 6 位”
   - 记住登录选项（可选）：
     - 复选框 + 文案 “7 天内免登录”。
3. **操作区域**
   - 主按钮：“登录”
     - 默认：不可点击（灰色），当账号+密码均非空时变为可点击状态（主色）。
   - 辅助文本按钮：
     - 左侧小字：“忘记密码？”（1.0 可不实现真正找回逻辑，只需点击后弹出提示“请联系辅导员重置密码”）
     - 右侧小字：“没有账号？使用学号登录即可”或简短说明。
4. **底部区域**
   - 一行灰色小字：“本系统仅限本校学生使用”。

**交互与流程**：

- 用户点击“登录”按钮：
  1. 前端先进行表单校验（账号 & 密码）；
  2. 如果校验不通过，在各输入框下显示对应红色错误文案；
  3. 校验通过后，显示加载状态（按钮变为“登录中...”并禁用再次点击）；
  4. 调用 SpringBoot 后端登录接口；
  5. 登录成功：
     - 保存用户信息与 token；
     - 跳转到首页；
  6. 登录失败：
     - 提示“账号或密码错误”，保持当前页面。

**状态**：

- 正常状态：展示表单；
- 加载状态：按钮显示 loading 动画/文字；
- 错误状态：输入框下的错误提示 + 统一 toast。

### 5.2 首页与全局导航模块

#### 5.2.1 首页

**页面名称**：首页
**入口**：

- App 启动且已登录时默认进入；
- 底部 TabBar 点击“首页”。

**页面结构布局**（自上而下）：

1. **顶部欢迎区**
   - 左侧：问候文案，如：
     - 第一行：`早上好，{昵称}`（根据时间段变化：早上好、中午好、下午好、晚上好）
     - 第二行：`今天也要加油学习哦！`
   - 右侧：圆形头像小图（点击可进入“我的”页面）。
2. **快捷功能入口宫格**
   - 区块标题：`常用功能`
   - 布局：2 行 x 3 列宫格（共 4–6 个入口）
   - 每个宫格内容（图标 + 文本）：
     1. 公告中心（→ 公告列表页）
     2. 二手市场（→ 二手列表页）
     3. 校园服务（→ 服务列表页）
     4. 消息中心（→ 消息列表页）
     5. 我的预约（→ 我的预约页，可选）
     6. 我的发布（→ 我的二手发布页，可选）
   - 点击行为：跳转对应模块页。
3. **最新公告预览区**
   - 标题行：
     - 左侧：“最新公告”
     - 右侧：“全部 >”（点击进入公告列表页）
   - 内容区：
     - 显示最近 2–3 条公告简要信息：
       - 标题（单行，过长截断）
       - 发布时间（日期）
       - 类型标签（如“教务”、“活动”）
     - 每条公告为一行，可点击跳转对应公告详情页。
4. **最近消息预览区**
   - 标题行：
     - 左侧：“最新消息”
     - 右侧：“全部 >”（进入消息列表页）
   - 内容区：
     - 显示与当前用户相关的最近 2–3 条消息：
       - 消息标题（如“你的预约已被受理”）
       - 时间
       - 未读状态小圆点（若是未读消息）。
5. **底部导航栏（TabBar）**（全局统一）
   - 四个 Tab：
     1. 首页（icon + “首页”）
     2. 二手（icon + “二手”）
     3. 服务（icon + “服务”）
     4. 我的（icon + “我的”）
   - 说明：当前页“首页”为高亮状态。

**交互要点**：

- 下拉刷新：首页整体支持下拉刷新数据（公告预览 & 消息预览）；
- 点击头像 → “我的”页面；
- 点击公告/消息标题 → 对应详情页面；
- 点击右上“全部 >” → 对应列表页面。

### 5.3 公告模块

#### 5.3.1 公告列表页

**页面名称**：公告列表
**入口**：

- 首页「公告中心」入口；
- 首页“最新公告”区右侧“全部 >”；
- 其他页面的链接入口（可选）。

**页面结构布局**：

1. **顶栏**
   - 左侧：返回按钮；
   - 中间：标题 `公告中心`；
   - 右侧：搜索图标按钮（点击弹出搜索框或滑出搜索区域）。
2. **筛选与搜索区**
   - 筛选标签栏（水平滑动）：
     - “全部”、“教务通知”、“活动讲座”、“奖学金”、“其他”等；
     - 当前选中标签高亮。
   - 搜索输入框（可折叠）：
     - 占位文字：`搜索公告标题关键字`
     - 右侧“搜索”按钮或仅回车触发。
3. **公告列表区**
   - 列表形式，每个列表项为一张“公告卡片”：
     - 标题（最多两行，超出省略）；
     - 简要描述（可选，1 行）；
     - 发布时间（日期或“3小时前”形式）；
     - 类型标签（小色块，如“教务”、“活动”等）；
   - 卡片样式：有轻微阴影或卡片边框，点击整卡区域即可进入详情。
4. **状态显示**
   - 加载中：列表区域中间展示 loading 动画或“加载中...”文字；
   - 空状态：当无数据时显示插画+文字“暂无相关公告”；
   - 错误状态：如加载失败时显示“加载失败，点击重试”。

**交互说明**：

- 切换筛选标签：重新加载对应类别公告列表；
- 搜索框输入关键字并提交：按关键字过滤列表；
- 下拉刷新：刷新当前筛选条件下的列表；
- 点击公告卡片：进入公告详情页，并传递公告 id。

      - 可为手机号或微信号；
      - 占位：`请输入手机号或微信号`
