# Spring Boot 第一周学习笔记

## 学习内容
1. Spring Boot 是什么
    - 是一个 Java 后端开发框架
    - 可以快速创建 Web 应用

2. 创建 Spring Boot 项目
    - 使用 IDEA 的 Spring Initializr
    - 选择 Spring Web 依赖

3. 写第一个 Hello 接口
    - @RestController 注解
    - @GetMapping("/hello") 注解
    - 返回字符串

4. Git 和 GitHub 使用
    - git init 初始化仓库
    - git add/commit/push 提交代码
    - SSH 连接 GitHub

## 遇到的问题
1. JDK 版本配置问题
    - 解决方法：在 pom.xml 中添加版本配置

2. GitHub 推送时分支名不匹配
    - 本地 master，远程 main
    - 用 git push origin master:main 解决
